# Module Spec - dashboard-ui

## Responsabilidade

Consolidar indicadores e visualizacoes de performance operacional do ecossistema.

## Entradas

- Agregacoes e metricas fornecidas pelo core.

## Saidas

- Cards de KPI.
- Graficos de tendencia e distribuicao.

## Dependencias

- Server Actions de dashboard.
- Biblioteca de graficos no frontend.
